# IT Asset Tracker

ระบบทะเบียนอุปกรณ์ไอทีแบบหน้าเดียว ใช้บันทึกว่าเครื่องไหนอยู่กับใคร มาแทนไฟล์ Excel ที่ส่งต่อกันทางอีเมลแล้วหาของไม่เจอ
ทำงานในเบราว์เซอร์ล้วน ไม่ต้องติดตั้งอะไร ไม่ต้องมีเซิร์ฟเวอร์ และใช้งานแบบออฟไลน์ได้

## ฟีเจอร์

**บันทึกข้อมูลอุปกรณ์**

- ฟอร์มเพิ่มอุปกรณ์ 6 ช่อง — ชื่ออุปกรณ์ ประเภท หมายเลขเครื่อง ผู้ถือครอง สถานะ หมายเหตุ
- ประเภท 5 แบบ (โน้ตบุ๊ก จอ เครื่องพิมพ์ สวิตช์ กล้องวงจรปิด) และสถานะ 5 แบบ (ว่าง ใช้งาน ซ่อม จำหน่ายออก สูญหาย)
- บังคับกรอกชื่ออุปกรณ์ ประเภท หมายเลขเครื่อง และสถานะ ส่วนผู้ถือครองและหมายเหตุเว้นว่างได้
- ตารางแสดงรายการทั้งหมดในหน้าเดียว

**ค้นหาและกรอง**

- ช่องค้นหาช่องเดียว พิมพ์แล้วกรองทันทีไม่ต้องกดปุ่ม ค้นจากชื่ออุปกรณ์ หมายเลขเครื่อง และผู้ถือครอง
- ไม่สนตัวพิมพ์เล็กพิมพ์ใหญ่
- กรองตามประเภทและตามสถานะ ใช้ซ้อนกับช่องค้นหาได้พร้อมกันทั้งสามชั้น
- ตัวนับบอกจำนวนที่พบ เช่น `พบ 5 จาก 12 รายการ`
- ถ้ากรองแล้วไม่เจอ จะขึ้นข้อความบอก ไม่ปล่อยตารางว่างเปล่า

**แก้ไขและลบ**

- ปุ่มแก้ไขในทุกแถว ดึงข้อมูลขึ้นฟอร์มเดิมที่สลับเป็นโหมดแก้ไข พร้อมปุ่มยกเลิก
- ปุ่มลบในทุกแถว มีกล่องยืนยันระบุชื่อเครื่องก่อนลบ

**ส่งออก CSV**

- ส่งออกเฉพาะรายการที่แสดงอยู่ในตารางตอนนั้น กรองไว้แบบไหนก็ได้ไฟล์ตามนั้น
- หัวตารางเป็นภาษาไทย ชื่อไฟล์ติดวันที่อัตโนมัติ เช่น `it-assets-2026-09-09.csv`
- ใส่ UTF-8 BOM ให้ เปิดด้วย Excel บน Windows แล้วภาษาไทยอ่านออกทันที

**การเก็บข้อมูล**

- บันทึกลง `localStorage` อัตโนมัติทุกครั้งที่ข้อมูลเปลี่ยน ไม่ต้องกดบันทึก
- ปิดเบราว์เซอร์แล้วเปิดใหม่ ข้อมูลยังอยู่

## วิธีใช้งาน

**1. เปิดโปรแกรม**

```bash
git clone <URL ของ repository>
cd it-asset-tracker
```

จากนั้นดับเบิลคลิกไฟล์ `index.html` หรือลากไปวางในเบราว์เซอร์

ถ้าเบราว์เซอร์บล็อกการดาวน์โหลดไฟล์ CSV ตอนเปิดจาก `file://` ให้เปิดผ่าน local server แทน แล้วเข้า `http://localhost:8000`

```bash
python3 -m http.server 8000
```

**2. เพิ่มอุปกรณ์**

กรอกฟอร์มด้านบนแล้วกด **เพิ่มอุปกรณ์** รายการจะโผล่ในตารางและถูกบันทึกทันที ไม่ต้องกดบันทึกอีกที

**3. ค้นหาหรือกรอง**

พิมพ์ในช่องค้นหา หรือเลือกประเภทและสถานะจากกล่องข้างๆ ตารางกรองให้ทันทีที่พิมพ์

**4. แก้ไข ลบ หรือส่งออก**

กด **แก้ไข** ในแถวที่ต้องการเพื่อดึงข้อมูลขึ้นฟอร์ม กด **ลบ** เพื่อลบออก (มีกล่องยืนยันก่อน) หรือกด **ส่งออก CSV** เพื่อเซฟรายการที่เห็นอยู่เป็นไฟล์

## เทคโนโลยีที่ใช้

| เทคโนโลยี | เหตุผล |
|---|---|
| HTML ไฟล์เดียว | เปิดจากไฟล์ในเครื่องได้ทันที ย้ายเครื่องแค่ก๊อปไฟล์เดียว |
| Vanilla JavaScript | ไม่มี build step ไม่มี dependency แก้โค้ดแล้วรีเฟรชเห็นผลทันที |
| CSS เขียนเอง | หน้าจอมีไม่กี่ส่วนและใช้บนเดสก์ท็อป ไม่ต้องพึ่ง framework |
| `localStorage` | เก็บข้อมูลได้โดยไม่ต้องมีเซิร์ฟเวอร์หรือฐานข้อมูล |

ไม่มี backend ไม่มีฐานข้อมูล ไม่มีระบบล็อกอิน ไม่มีไลบรารีภายนอกแม้แต่ตัวเดียว และไม่ต้องต่ออินเทอร์เน็ตตอนใช้งาน

## ข้อจำกัดที่ควรรู้ก่อนใช้

> ⚠️ **ข้อมูลอยู่ในเบราว์เซอร์ของเครื่องที่คุณใช้เท่านั้น** ล้างข้อมูลเบราว์เซอร์ เปลี่ยนเบราว์เซอร์ เปลี่ยนเครื่อง หรือเปิดในโหมดไม่ระบุตัวตน แล้วข้อมูลจะไม่อยู่ที่นั่น

- **ไฟล์ CSV ที่ส่งออกไม่ใช่ไฟล์สำรองข้อมูล** เพราะเวอร์ชันนี้ยังไม่มีฟังก์ชันนำเข้าข้อมูลกลับ ส่งออกไปดูหรือส่งต่อได้ แต่นำกลับเข้าระบบไม่ได้ ถ้าข้อมูลใน `localStorage` หาย ต้องกรอกใหม่ทั้งหมด
- ไม่มีการสำรองข้อมูลอัตโนมัติ
- เปิดคนละเครื่องหรือคนละเบราว์เซอร์คือคนละชุดข้อมูล ไม่มีการซิงก์ให้
- ใช้ได้ทีละคน ไม่มีระบบล็อกอิน ใครเข้าถึงเครื่องนั้นได้ก็แก้ข้อมูลได้ ต้องคุมด้วยการล็อกเครื่องแทน
- ลบแล้วหายถาวร ไม่มีถังขยะและไม่มีปุ่มเลิกทำ
- ไม่มีประวัติการแก้ไข แก้ทับแล้วไม่รู้ว่าค่าเดิมคืออะไรและใครแก้
- ยังไม่รองรับหน้าจอมือถือ ออกแบบมาสำหรับคอมพิวเตอร์ที่โต๊ะทำงาน
- เหมาะกับข้อมูลระดับหลักร้อยรายการ ถ้าโตกว่านั้นหรือมีผู้ใช้หลายคนพร้อมกัน ควรย้ายขึ้นเซิร์ฟเวอร์พร้อมฐานข้อมูลจริง
