# IT Asset Tracker — ระบบทะเบียนอุปกรณ์ไอที

ระบบทะเบียนอุปกรณ์ไอทีสำหรับทีมไอทีขององค์กร ใช้บันทึกอุปกรณ์ประมาณ 200 ชิ้น ทั้งโน้ตบุ๊ก จอ เครื่องพิมพ์ สวิตช์ และกล้องวงจรปิด มาแทนไฟล์ Excel ที่ส่งต่อกันทางอีเมล ซึ่งมีปัญหาคือค้นหาข้อมูลไม่เจอ ไม่รู้ว่าเครื่องไหนอยู่กับใคร และมีหลายเวอร์ชันจนไม่รู้อันไหนล่าสุด

ระบบนี้ตอบสองคำถามหลักให้ได้ภายในไม่กี่วินาที คือ **เครื่องนี้อยู่กับใครและอยู่ที่ไหน** และ **ประกันของเครื่องไหนกำลังจะหมด** พร้อมเก็บประวัติทุกการเปลี่ยนแปลงไว้ตรวจย้อนหลังได้ ทำงานในเบราว์เซอร์อย่างเดียว ไม่ต้องติดตั้งอะไรและไม่ต้องมีเซิร์ฟเวอร์

## ฟีเจอร์

**จัดการข้อมูลอุปกรณ์**
- ตารางแสดงรายการอุปกรณ์ทั้งหมดในหน้าเดียว
- ช่องค้นหาช่องเดียว ค้นได้ทั้งรหัสอุปกรณ์ serial ยี่ห้อ รุ่น ชื่อผู้ถือครอง และสถานที่
- กรองตามประเภท สถานะ และผู้ถือครอง
- สร้างรหัสอุปกรณ์อัตโนมัติตามประเภท เช่น `NB-0042`, `CAM-0007`
- เตือนเมื่อกรอกหมายเลข serial ซ้ำกับเครื่องที่มีอยู่แล้ว

**ยืม-คืน**
- ปุ่มจ่ายออก เปลี่ยนสถานะ ผู้ถือครอง แผนก และวันที่จ่ายให้ในคลิกเดียว
- ปุ่มรับคืน ล้างข้อมูลผู้ถือครองและคืนสถานะเป็นว่างอัตโนมัติ
- ค้นด้วยชื่อคน เห็นครบทุกเครื่องที่คนนั้นถืออยู่

**ประวัติ**
- บันทึกทุกการเปลี่ยนแปลงอัตโนมัติ ทั้งค่าเดิม ค่าใหม่ และเวลา
- หน้ารายละเอียดรายเครื่อง แสดงข้อมูลปัจจุบันและประวัติย้อนหลังทั้งหมด
- ประวัติแก้ไขหรือลบไม่ได้

**แจ้งเตือนและสรุป**
- แจ้งเตือนอุปกรณ์ที่ประกันจะหมดภายใน 30 และ 90 วัน
- สรุปจำนวนอุปกรณ์แยกตามประเภทและสถานะ
- เตือนให้สำรองข้อมูลถ้าไม่ได้ export มาเกิน 3 วัน

**การเก็บข้อมูล**
- บันทึกลง `localStorage` อัตโนมัติ ไม่ต้องกดบันทึก
- Export ข้อมูลทั้งหมดเป็นไฟล์ JSON พร้อมวันที่ในชื่อไฟล์
- Import ไฟล์ JSON กลับเข้ามาได้ พร้อมตรวจสอบโครงสร้างไฟล์ก่อนนำเข้า

## วิธีเปิดใช้งาน

ไม่ต้องติดตั้งอะไร ไม่ต้องมี Node.js ไม่ต้องรัน build

**วิธีที่ 1 — เปิดจากไฟล์โดยตรง**

```bash
git clone <URL ของ repository>
cd it-asset-tracker
```

จากนั้นดับเบิลคลิกไฟล์ `index.html` หรือลากไฟล์ไปวางในเบราว์เซอร์

**วิธีที่ 2 — เปิดผ่าน local server** (แนะนำ เพราะ `localStorage` ทำงานเสถียรกว่า)

```bash
python3 -m http.server 8000
```

แล้วเปิด `http://localhost:8000` ในเบราว์เซอร์

### การใช้งานครั้งแรก

1. เปิดหน้าเว็บ กดปุ่มเพิ่มอุปกรณ์เพื่อกรอกข้อมูลเครื่องแรก
2. ถ้ามีไฟล์ข้อมูลเดิมอยู่แล้ว กดปุ่ม Import แล้วเลือกไฟล์ JSON
3. **กด Export ทุกครั้งที่เลิกใช้งาน** แล้วเก็บไฟล์ไว้บน cloud storage

> ⚠️ ข้อมูลเก็บอยู่ใน `localStorage` ของเบราว์เซอร์ ถ้าล้างข้อมูลเบราว์เซอร์หรือเปิดในโหมด incognito ข้อมูลจะหาย **ไฟล์ JSON ที่ export ไว้คือข้อมูลจริง** สิ่งที่อยู่ในเบราว์เซอร์เป็นแค่ที่ทำงานชั่วคราว

## เทคโนโลยีที่ใช้

| เทคโนโลยี | เหตุผล |
|---|---|
| HTML ไฟล์เดียว | เปิดจากไฟล์ในเครื่องได้ทันที ย้ายเครื่องแค่ก๊อปไฟล์เดียว |
| Vanilla JavaScript | ไม่มี build step ไม่มี dependency แก้โค้ดแล้วรีเฟรชเห็นผลทันที |
| CSS เขียนเอง | หน้าจอมีไม่กี่หน้าและใช้บนเดสก์ท็อป ไม่ต้องพึ่ง framework |
| `localStorage` | เก็บข้อมูลระหว่างทำงานโดยไม่ต้องมีฐานข้อมูล |
| ไฟล์ JSON | รูปแบบข้อมูลจริงที่ใช้สำรองและย้ายข้อมูล |

ไม่มี backend ไม่มีฐานข้อมูล ไม่มีระบบล็อกอิน และทำงานได้โดยไม่ต้องต่ออินเทอร์เน็ต
